# Hero Saga

Trauma-to-Epic Narrative Engine. 유저의 불쾌한 경험을 5단계 영웅 서사로 변환하는 Next.js 인터랙티브 데모.

## Setup
1. `cp .env.local.example .env.local` 후 `ANTHROPIC_API_KEY` 채우기
2. `npm install`
3. `npm run dev` → http://localhost:3000
